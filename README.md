# infosustentabilidade-digital-grupo-grgs
🌱 InfoSustentabilidade

Projeto desenvolvido pelos estudantes Gabriel Riscarolli e Gabriel Schmoller com o objetivo de promover a conscientização sobre sustentabilidade, descarte correto de resíduos eletrônicos e impactos ambientais causados pelo consumo tecnológico.

📖 Sobre o Projeto

O InfoSustentabilidade é um projeto educacional e informativo criado para pesquisar, organizar e divulgar informações relacionadas à sustentabilidade tecnológica, focando principalmente em:

♻️ Descarte correto de lixo eletrônico;
🌍 Impactos ambientais do consumo excessivo de tecnologia;
🔋 Reutilização e reciclagem de componentes eletrônicos;
📱 Conscientização sobre consumo sustentável;
🏙️ Pesquisa de pontos de coleta e iniciativas locais.

O projeto busca unir tecnologia e responsabilidade ambiental, incentivando práticas sustentáveis dentro da comunidade escolar e regional.

🎯 Objetivos
Informar sobre os riscos do descarte incorreto de eletrônicos;
Incentivar a reciclagem e reutilização de equipamentos;
Apresentar dados e pesquisas sobre sustentabilidade;
Desenvolver consciência ambiental através da tecnologia;
Criar materiais educativos acessíveis para estudantes.
